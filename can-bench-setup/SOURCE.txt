    위치   환경변수 JOULE_HOME, 없으면 D:\Ljindong\joule
    원격   git@github.com-ljindong:ljindong1/Joule.git
    실행   uv run --directory <Joule> joule-bench | joule-sleep | joule-deep <결선>
    설정   <Joule>\configs\ (devices / targets / benches / tests)
    기록   <Joule>\runs\  — run.json 에 Joule git 커밋·수정 여부가 남는다
