# 도메인 아이콘 글리프 라이브러리

카드 헤더·배지·범례에 쓰는 아이콘. **아래 path를 그대로 복사**해 쓴다(즉석 창작 금지 — 톤이 흔들린다). 폴더트리 글리프와 같은 철학: 규격이 같아야 어떤 다이어그램에서도 통일돼 보인다.

## 공통 규격

- 좌표계: **18×18 그리드** (0~18)
- 스타일: **stroke 스타일** — `fill="none"`, `stroke-width="1.2"`, `stroke-linecap="round"`, `stroke-linejoin="round"`
- 색: 배치되는 카드의 **톤 stroke 색** 또는 **진한 텍스트 색**. 배지(§11-4) 안에서는 흰색.
- 배치: `<g transform="translate(x,y)">` 로 이동, 크기 조절은 `scale()`. 표준 크기 18px(scale 1), 배지 원(r=13 확대형) 안은 scale 0.8.
- 스타일 클래스로 일괄 지정 권장:

```svg
<style>
  .icon { fill: none; stroke-width: 1.2; stroke-linecap: round; stroke-linejoin: round; }
</style>

<!-- 사용 예: 카드 타이틀 왼쪽 -->
<g transform="translate(40, 66)">
  <path class="icon" stroke="rgb(24,95,165)" d="{아래 표에서 복사}"/>
</g>
```

- 카드 헤더에 아이콘을 넣으면 타이틀 x는 아이콘 left + 26.
- 세로 중심: 아이콘 중심(9,9)이 타이틀 시각적 중심과 맞도록 translate y = 타이틀 baseline − 15.

## 사용 원칙

- 다이어그램당 **6개 이하** (SKILL.md §12 가드레일)
- 의미 전달이 목적 — 장식으로 모든 카드에 붙이지 않는다
- 같은 다이어그램 안에서 아이콘 크기는 통일 (18px 하나로)
- 새 아이콘이 꼭 필요하면 이 규격(18×18, stroke 1.2, round)으로 만들고 **이 파일에 추가**해 재사용한다
