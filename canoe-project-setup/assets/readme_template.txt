[CAN DB]
---------------------------------------------------------------------
저장소의 References/DB 최상위에 있는 것이 현행이다. 구버전은 unused/ 로
내려가 있으므로, 최상위에 무엇이 있는지가 곧 "지금 맞는 DB" 다.

{DB_NOTE}

DB 가 바뀌면 신호 이름과 메시지 구성이 달라질 수 있다. 측정이 이상하면
저장소 DB 와 이 폴더의 DB 가 같은지부터 본다.

      python scripts\canoesetup.py verify --dir . --repo "{REPO}"


[진단(CDD)]
---------------------------------------------------------------------
{DIAG_NOTE}

CDD 는 ECU 진단 사양서를 기계가 읽는 형태로 만든 것이다 (CANdela XML).
안에 DTC 목록, DID 와 그 해석 규칙, 지원 서비스, 보안접근(0x27) 규칙이
들어 있다. CANoe 에 물리면 Diagnostic Console 에서 버튼으로 진단을 보내고
응답을 사람이 읽는 형태로 풀어준다. 없으면 raw hex 로 직접 쳐야 한다.

물리는 곳
      Diagnostics / ISO TP  ->  진단 기술(Diagnostic Description) 추가
      짝이 되는 Seed&Key DLL 도 같이 지정한다 (HKMC_AdvancedSeedKey_Win32.dll)


[채널 연결]
---------------------------------------------------------------------
CANoe 안에서 쓰는 채널 번호는 논리 번호다. 실제 장비 채널은
Vector Hardware Manager 에서 배정한다. VN1640A 의 CH3 / CH4 에 꽂았어도
CANoe 채널 1 / 2 에 배정하면 된다.

      CANoe 채널 1   Body CAN (B2)
      CANoe 채널 2   Local CAN (PSU_DRV)


[데이터가 안 나올 때 — 먼저 볼 것]
---------------------------------------------------------------------
채널이 CAN FD 가 아니라 Classic CAN 으로 설정돼 있지 않은지 본다.

이 설정은 .cfg 안에 없다. Vector Hardware Manager 에 있고, 저장 형식이
바이너리라 파일로는 확인도 수정도 못 한다. 그래서 컨피그는 완벽한데
데이터만 0 인 상태가 된다. 에러 프레임이 쏟아지면 거의 이것이다.

      Vector Hardware Manager -> 해당 채널 -> CAN FD 로 설정
      중재 구간 500 kbit/s, 데이터 구간은 저장소 Ecud_Can.arxml 기준

그다음 순서
      1. 보드에 전원과 IGN 이 들어갔나 (B+ 만으로는 슬립)
      2. 디버거로 main 에서 멈춰 둔 상태는 아닌가 (CPU 정지 = 송신 없음)
      3. 종단저항
      4. 채널 배정 (Hardware Manager)


[폴더 밖을 가리키는 참조]
---------------------------------------------------------------------
이 컨피그에는 폴더 밖을 가리키는 참조가 {OUTSIDE}건 있다. 로그 파일 경로,
CANoe 기본 템플릿, 테스트 보고서 경로다. 측정을 막지는 않지만 원본을
만든 PC 의 흔적이므로, 로깅을 쓸 때는 출력 경로를 먼저 확인한다.


[검증]
---------------------------------------------------------------------
      python scripts\canoesetup.py verify --dir . --repo "{REPO}"

보는 것
      폴더 안 참조가 전부 실재하나
      다른 차종 이름이 남아 있나
      진단 기술이 물려 있나
      CAN DB 가 저장소 현행과 같나
      컨피그가 참조하지 않는 파일이 있나


[열지 않고 확인]
---------------------------------------------------------------------
      python scripts\canoesetup.py check --dir .

CANoe 를 COM 으로 잠깐 띄워 컨피그를 열고 DB 목록과 시뮬레이션 노드를
읽은 뒤 닫는다. 측정을 시작하지 않으므로 버스로 아무것도 내보내지 않는다.
산출물은 _autorun\ 에 남는다 (check.ps1, check_log.txt).
