## 이 제어기에서 조심할 것

- ⚠ **CF 108 의 목록에는 `BJ/TPMS` 하나뿐이다.** 우리가 작업하는 것은 파생 **LT2** 인데 목록에 LT2 항목이 없어서 BJ 값을 쓴다. **제목은 `LT2`, 계열 필드는 `BJ`** 로 갈리는 것이 정상이다.
- ⚠ **차량단계가 차종마다 다르다** — BJ/TPMS 는 양산(SOP 완료), LT2/TPMS 는 P2 배포 중·M 단계 예정. 선례는 `P2(LP2)` 를 썼다(LT2 기준). **다른 차종에 쓰면 다시 묻는다.**
- **상위 "SWP 모듈 패치 적용 건" 일감이 없다.** PSU 는 #49002 가 그 자리인데 TPMS 에는 없어서 `relates` 를 걸 상대가 짝 구분 일감뿐이다. **만들지 말고 사용자에게 알린다.**
- 제어기 토큰은 `TPMS RF Receiver` **전체**를 쓴다(사내 제목 태그 빈도 9 회). `TPMS` 로 줄인 선례도 있으나 검색 키가 갈린다.
