# 출력 형식 (P7) — 정본

이 문서의 헤더·이모지·순서·머리표·링크라벨 규칙을 **매번 글자 그대로** 지킨다. 임의로 섹션을 빼거나 순서를 바꾸지 않는다.

## 서식 규칙 (어기면 슬랙에서 깨진다)

`slack_send_message`는 **표준 마크다운**을 받아 슬랙 서식으로 변환한다.

- **볼드는 별표 2개** `**텍스트**`. 별표 1개 `*텍스트*`는 이탤릭이니 **절대 쓰지 말 것**.
- 최상단 브리핑 제목은 `# `, 대분류(§A/§B)는 `## `, 그 안의 섹션은 `### `.
- 항목 소제목(`[머리표] 제목`)은 헤더가 아니라 `**볼드**`로 처리해 헤더와 계층을 구분한다.
- 표(`| ... |`)와 링크(`[라벨](URL)`)는 표준 마크다운 그대로.

## 링크라벨 표기 규칙 (고정)

- **채널 메시지**: `🔒채널명에서 한글이름(English Name) 님`
- **DM**: `한글이름(English Name)`

## 전체 골격

```
# 🌅 {대상 접두}아침 브리핑 ({수집 시작 시각} ~ 현재 기준, {TODAY})

## 👤 내 업무

### ✅ 1. 오늘 안에 액션이 필요한 것
### 📅 2. 새로 잡혔거나 확인된 일정
### 📌 3. 참고만 하면 되는 공지·논의

## 📡 채널 동향

### {채널 라벨} ({건수}건)
### {채널 라벨} ({건수}건)

---
🧾 소인 채널 {N} / DM {M} · 수집 {C} · 채택 {A} · 제외 {D} · 미등록 소스 {U}
```

### 헤더

- **대상 접두**: 기본(이진동)이면 접두 없이 `# 🌅 아침 브리핑 ...`. 대상 지정 시 `# 🌅 홍길동님 아침 브리핑 ...`
- 직전 브리핑을 찾았으면 그 시각 표기 → `# 🌅 아침 브리핑 (7/30 08:06 ~ 현재 기준, 2026-07-31)`
- 폴백(직전 브리핑 없음)이면 → `# 🌅 아침 브리핑 (어제 0시 ~ 현재 기준, 2026-07-31)`
- **`{TODAY}`는 `scripts/context.py now`가 준 값만 쓴다.** 직전 브리핑 헤더에서 복사하지 않는다.

## §A 내 업무

내용 없는 섹션도 **제목은 남기고** 그 아래 `- 해당 없음` 한 줄만 적는다.

### `### ✅ 1. 오늘 안에 액션이 필요한 것`

- 각 건은 `**[머리표] 제목**`으로 시작. 머리표는 급한 순:
  `[★ 최우선]` › `[회신 필요]` › `[확인 필요]` › `[검토]` › `[참석]`
- 제목에 마감·시작 시각을 포함한다.
- 제목 아래 `•` 불릿 2~3개: ① 누가·언제·무엇 ② 맥락/판단 ③ 필요한 액션
- 마지막 불릿은 원문 링크: `• 🔗 [링크라벨](permalink)`

### `### 📅 2. 새로 잡혔거나 확인된 일정`

```
| 일시 | 내용 |
| --- | --- |
| 6/27(금) 14:00 | 고용재 AI면접 (Google Meet 예상) |
```

표 아래에 각 일정의 출처를 `•` 불릿으로: `• [설명]: 🔗 [링크라벨](permalink)`

"화/수/목" 같은 상대 요일 표현은 **메시지 작성일 기준**으로 실제 날짜로 환산하고, 요일은 그 날짜에서 계산해 붙인다(눈대중 금지). 취소·불참·시간변경도 이 섹션이다.

### `### 📌 3. 참고만 하면 되는 공지·논의`

각 건을 `•` 불릿 한 줄로 요약하고, 바로 다음 줄에 `  → 🔗 [링크라벨](permalink)`

## §B 채널 동향

**소인한 채널 중 채택 건이 1건 이상인 채널만** 소제목을 만든다. 건수 0인 채널은 적지 않는다(푸터의 소인 채널 수에는 포함된다).

채널 소제목: `### 🔒채널명 (N건)` — 비공개는 🔒, 공개는 `### #채널명 (N건)`

### 밀도 — 하이브리드

**개별 승격**(1건 = 1불릿 + 링크)할 것:

- `@channel` / `@here` 공지
- 일정 신설·변경·취소·연기
- 파일·문서 공유
- 질문·요청·검토 의뢰
- 결정 사항·사양 변경
- 이슈·블로커·장애
- 정형 스탠드업이라도 **"이슈/막힌 점"에 내용이 있는 것**

**접기**할 것:

- 특이사항 없는 정형 스탠드업 등 반복 서식 → 마지막에 한 줄로 묶는다

형식:

```
### 🔒모베이스에이에쓰이씨-공통 (2건)
• **[최연훈 07/30 10:45]** `@channel` 모베이스전자·연구개발실 소개 자료 공유 — 소프트웨어아키텍처설계실_소개_260730_v02.pptx (8.7MB)
  → 🔗 [🔒모베이스에이에쓰이씨-공통에서 최연훈(Choi YeunHun) 님](permalink)
• **[한창우 07/29 09:34]** 오토에버 AI 업무 적용 사례 — 금일 오후 5시 진행
  → 🔗 [🔒모베이스에이에쓰이씨-공통에서 한창우(Han ChangWoo) 님](permalink)

### #daily-standup (11건)
• **[최연훈 07/30 07:11]** 오늘: 면접 · 주간보고 제출 · 아키텍처설계실 소개 정리 · 연구개발실 미팅
  → 🔗 [🔒daily-standup에서 최연훈(Choi YeunHun) 님](permalink)
• 그 외 스탠드업 10건 (오준석·김수영·서진우·김수홍·한무희·김지훈·강우석·이창수) — 특이사항 없음
```

### 중복 표시

§A에 실은 건은 §B에서 한 줄 참조만:

```
• **[최연훈 07/30 10:45]** `@channel` 연구개발실 소개 자료 공유 → 내 업무 §1 참조
```

## 감사 푸터 (필수)

브리핑 맨 아래에 `---` 구분선 뒤 한 줄:

```
🧾 소인 채널 4 / DM 6 · 수집 23 · 채택 9 · 제외 14 · 미등록 소스 0
```

- 이 한 줄이 커버리지를 눈에 보이게 만든다. "소인 채널 4"인데 §B에 채널이 1개뿐이면 나머지가 조용했다는 뜻이고, 소인 채널 수 자체가 줄면 레지스트리 문제다.
- **미등록 소스가 1 이상이면** 푸터 다음 줄에 붙인다:
  ```
  ⚠️ 미등록 채널 감지: #proj_2026모빌진-기반-차세대-미들웨어플랫폼 (C0AAU64LUG0, 2건) — sources.json 등록 권장 (등록 전까지 매일 재안내)
  ```
- **접근 불가 소스가 1 이상이면** 반드시 한 줄 붙인다. 이 문구가 없으면 게이트#2가 발송을 막는다:
  ```
  ⚠️ 접근 불가 1건: #jg-wpc-개발-협업 (C0BBAAX300M) — channel_not_found. 삭제·이탈 여부 확인 필요
  ```
  푸터에 표시한 뒤 게이트를 호출할 때 `--ack-unavailable` 을 붙인다.
- **30일 연속 0건인 채널**이 있으면 정리 제안을 한 줄 붙인다:
  ```
  ℹ️ #proj-wpc 30일 무트래픽 — retired_channels 이동 검토
  ```

## 관련 항목이 전혀 없을 때

헤더와 골격은 그대로 유지하고 각 섹션에 `- 해당 없음`을 남긴다. §B는 `- 채널 활동 없음`. 푸터는 정상 출력한다. **빈 브리핑도 발송한다.**
