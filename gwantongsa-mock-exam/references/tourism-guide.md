# 관광자원해설 출제 가이드

관광통역안내사 필기 관광자원해설(배점 20%, 25문항, 4지선다)의 출제 규칙.
이 과목의 절대 원칙: **바뀐 법령·제도·지정 현황을 반드시 최신 기준으로 반영한다.** 낡은 교재 지식으로 문제를 내면 오답을 가르치게 된다.

## 생성 전 필수 최신화 체크 (매회 웹 검색으로 확인)

문제를 만들기 전에 아래 항목을 웹 검색으로 확인하고, 관련 문항에 최신 상태를 반영하라. 검색 예: "유네스코 세계유산 한국 목록 [올해년도]", "국립공원 지정 현황", "관광진흥법 개정".

1. **유네스코 등재 현황**: 세계유산 / 인류무형문화유산 / 세계기록유산의 한국 등재 목록과 최신 등재 건 (등재 연도 포함)
2. **국가유산 체제** (아래 별도 절 참고) — 용어·기관·분류가 맞는지
3. **국립공원·지질공원·람사르 습지** 지정 현황 변화 (신규 지정, 구역 변경)
4. **관광진흥법·관광기본법** 최근 개정 사항 (관광특구, 관광단지, 호텔업 등급 등)
5. **슬로시티, 생물권보전지역** 등 국제 지정 현황
6. **국보·보물 등 지정 변경** (신규 지정, 지정 해제, 명칭 변경 — 예: 보신각 동종 같은 명칭 정비)

## 국가유산 체제 (2024. 5. 17. 시행 — 반드시 이 체제로 출제)

「국가유산기본법」 시행으로 60년 된 '문화재' 체제가 '국가유산' 체제로 전면 개편되었다. 구 용어로 출제하면 그 자체가 오답이다.

- 기관: 문화재청 → **국가유산청**
- 총칭: 문화재 → **국가유산** (역사적·예술적·학술적·경관적 가치가 큰 유산)
- 3대 분류: **문화유산**(유형: 국보·보물·사적 등) / **자연유산**(천연기념물·명승) / **무형유산**(전통 공연·예술·기술 등)
- 등록문화재 → **국가등록문화유산**, 시도등록문화재 → 시도등록문화유산
- '인간문화재'로 불리던 보유자 제도는 무형유산 체제로 유지
- 지정 번호 제도: 2021년부터 국보·보물 등의 지정번호를 표기하지 않음 ("국보 제1호" 표현 금지, "국보 숭례문"으로 표기)

이 개편 자체가 최신 출제 포인트다(분류 체계, 기관명, 용어 변경을 묻는 문제). 단, 세부 사항은 매회 웹 검색으로 재확인하라 — 이 문서 작성 이후 또 바뀌었을 수 있다.

## 출제 영역 배분 (25문항 기준, category 태그)

| category | 문항 수 | 내용 |
|----------|---------|------|
| 자연 | 5~7 | 국립공원, 산·하천·동굴·해안, 천연기념물, 람사르 습지, 지질공원 |
| 문화유산 | 6~8 | 궁궐·성곽·사찰·탑·불상, 국보·보물, 사적, 전통 건축 양식 |
| 무형유산 | 3~4 | 무형유산 종목(판소리·탈춤 등), 보유자 제도 |
| 유네스코 | 3~4 | 세계유산·무형문화유산·기록유산 등재 목록과 등재 기준 |
| 축제·지역 | 3~4 | 지역 축제, 관광지·관광단지·관광특구, 슬로시티, 온천·동굴 등 |
| 제도·법령 | 2~3 | 국가유산 체제, 관광진흥법상 분류, 지정 제도 |

(±1 조정 가능. 합계 25문항 유지.)

## 문제 작성 원칙

- **중복 금지가 핵심 요구사항**: 이력 로그의 키워드와 대조해 이미 낸 소재(같은 궁궐, 같은 축제, 같은 국립공원)는 제외하고, 기출에서도 덜 다뤄진 소재를 우선 발굴하라. 기출 확인 출처: Q-net, cbtbank.kr, comcbt.com.
- 지역-자원 연결형(예: "다음 중 전라남도에 있는 관광자원이 아닌 것은?"), 공통 속성형(예: "유네스코 세계기록유산으로만 묶인 것은?"), 최신 제도형을 골고루.
- 숫자·지정 연도·소재지는 반드시 웹 검색으로 재확인. 애매하면 그 소재를 버리고 확실한 소재로 교체한다. **확신 없는 사실로 문제를 만들지 마라.**
- 해설에는 정답 근거 + 오답 각각의 실제 소재지/지정 현황을 적어 학습 자료가 되게 한다.
